# காவலர் குடும்ப நல அறக்கட்டளை - Police Family Welfare Portal (Tamil Nadu)

Full-stack web application built for **காவலர் குடும்ப நல அறக்கட்டளை** (Police Family Welfare Trust, Tamil Nadu).

## Stack
- **Frontend**: React (Vite) + Tailwind CSS + Lucide Icons + Tamil/English Bilingual UI
- **Backend**: Python FastAPI + SQLAlchemy ORM + Pydantic V2
- **Database**: SQLite (Local) / PostgreSQL (Production)

## Deployment Configuration
Included `render.yaml` blueprint for 1-click free deployment on [Render.com](https://render.com).
